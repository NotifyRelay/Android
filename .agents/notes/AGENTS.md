# AGENTS.md — Agent Notes

Agent Note 实质是 agent 撰写的 RFC：保留依据、替代方案、后果与必需验证的持久提案与决策记录。遵循[文档标准](../../Docs/AGENTS.md)与 [Agent Note 规则](README.md)。

**每份新增 Agent Note 都触发一次取代检查。** 在活跃目录树中搜索覆盖同一决策或机制的旧记录，判定是完整取代还是部分取代，并在同一 PR 中归档每一组符合条件的已实施记录。部分取代的记录保持活跃并互相链接。

[`archived/`](archived/AGENTS.md) 下的文件是冻结的历史快照：永不编辑，也不得将其视为当前权威依据。
