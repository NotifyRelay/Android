# Agent Note: 构建验证口径以命令形式固化

Status: implemented

## Problem

本仓库的构建与验证有若干无法从代码推导的前提：Gradle 需要访问用户目录、pwsh 会拆散 `-Pkey=value`、取干净编译警告在 Gradle 9.7.1 上已无全局 `--rerun`、代码索引建在工作区根。缺这些前提时验证会得到失真结果或直接失败，而失败原因看起来与改动无关。

## Decision

构建环境、警告基线、干净警告命令、比对口径与工作树约定固化为可照抄的命令与数值，见[构建与验证](../../../../Docs/构建与验证.md)。

## Alternatives considered

**用 `--rerun-tasks` 取干净警告。** 它会连带重跑原生任务，在 17GB 产物的模块上代价不可接受，且大部分原生任务与 Kotlin 警告无关。

**保留行号做警告比对。** 任何一次格式化或导入调整都会让行号平移，比对结果退化成全部新增加全部消失，失去判定能力。

**在 `Android/` 下单独建 CodeGraph 索引。** 子仓索引与工作区根索引会产生两份事实，且跨端改动无法在一次查询里覆盖。

## Consequences

验证命令必须按文档形式书写，简写会得到失真结果。警告基线变动时同步更新文档里的数值。
