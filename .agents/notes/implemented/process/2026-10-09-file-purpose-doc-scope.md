# Agent Note: 文件用途说明只写当前状态

Status: implemented

## Problem

`Docs/文件用途基础说明.md` 曾同时承载目录树、文件清单、`.kt` 计数、命名缘由与迁移沿革。前三类可被工具实时推导且历来是漂移源，出现过表头计数与树形列表双重失真；后两类违反禁止解释性描述的全局规则，读者要在一堆历史叙述里找当前契约。

## Decision

该文档只写当前状态：模块清单与依赖、各模块包根、类与公开方法、构建事实，以及单一入口这类描述当前设计约束的契约。目录树与文件清单由 CodeGraph 索引实时提供。

## Alternatives considered

**保留目录树作为快速参考。** 它每加一个文件就要同步，且无法通过门禁校验是否同步，最终必然漂移。索引能实时回答同类问题，且不会过期。

**把迁移沿革移到独立的历史文档。** 沿革属于 Git 提交与 Agent Note，单独维护一份历史文档等于第二个事实来源，同样会漂移。

## Consequences

改模块结构时只更新包根与契约，不补文件清单。需要知道某文件在哪时用代码检索，不要指望该文档列举。
