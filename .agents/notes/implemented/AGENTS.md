# AGENTS.md — 已实施 Agent Note

这些 Agent Note 描述已交付的决策。遵循根指令、[文档标准](../../../Docs/AGENTS.md)与 [Agent Note 格式](../README.md#the-file-format)；`verify-agent-note-format` 门禁校验各生命周期专属的结构。

<a id="keep-an-implemented-agent-note-current-with-what-actually-shipped"></a>

## 让已实施的 Agent Note 与实际交付内容保持同步

在改动路径、符号、默认值或机制的同一个变更中让它们保持最新。就地改写过时事实；不要追加变更历史。

当一份已交付记录不太可能再指导未来工作时，归档其完整三文件组，而不是继续维护它。

<a id="this-is-not-a-license-to-rewrite-the-decision"></a>

### 这不是重写*决策*的许可

就地更新事实层面的实现。推翻决策或其依据需要新的 Agent Note 并互相链接；只有通过 [Agent Note 规则](../README.md)中的合并规则，才能删除被完全取代的旧记录。
