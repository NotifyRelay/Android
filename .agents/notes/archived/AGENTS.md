# AGENTS.md — 归档 Agent Note

各类别目录下的归档 Agent Note 三文件组是冻结的历史快照，不是当前权威依据。对已封存制品永不编辑、重新格式化、翻译、修复、删除或移动；新的决策与事实请写入活跃 Agent Note 或当前文档。

归档变更只允许：移动完整的三文件组（英文、中文与伴随记录），在两种语言的 `Status: implemented` 行下方插入相同的 `Archived: YYYY-MM-DD` 行，重新记录伴随记录，并修复或删除入站链接。不要检查、校验或修复归档记录向外的链接。

用 `pnpm run verify-archived-agent-notes --write` 追加新的制品哈希。常规校验会拒绝被改动或缺失的已封存制品、不完整的三文件组、未知的类别目录以及非法的归档元数据。
