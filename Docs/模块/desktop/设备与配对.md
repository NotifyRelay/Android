# `:desktop` — 设备与配对

设备列表、报文入站与配对依赖注入，均位于 `notifyrelay.desktop.device` 包。端口契约见[模块结构](../../模块结构.md)，配对报文语义见[桌面端](../../桌面端.md#pairing)。

### `DesktopDeviceManager.kt`

设备列表与配对：状态来自 core 快照，配对经 `PairingCoordinator`；发送经 `ProtocolSender`，入站通知回调集合与 `DeviceAuthTablePort` 实现，在线设备缓存落 `Storage`；启动、周期广播与配对应答带本机带符号电量，电源变化时更新心跳调度器参数

### `DesktopDevicePortsProvider.kt`

设备端口提供者（查询/管理/消息/聊天），消息与聊天端口转发到同一管理器

### `DesktopDataMessagePort.kt`

入站数据报文端口：通知报文广播到管理器回调集合；应用列表与图标回包交由 `AppListSyncManagerCore`/`IconSyncManagerCore`（本机应用不列出时回空列表、图标回 missing）；其余报文空实现

### `DesktopDeviceScreen.kt`

设备列表页

### `MachineName.kt`

本机设备名解析
