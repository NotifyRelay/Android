# `:desktop` — 入口与数据层

KMP 桌面端入口，仅 `jvmMain`（jvm 单目标 + Compose Desktop）。包根 `notifyrelay.desktop`。

### `Main.kt`

入口：初始化数据层 → core 自检 → 启动设备管理 → 声明原生托盘与菜单 → 按 `ThemePort` 应用 `NotifyRelayTheme` 深浅色 → 提供各端口与 `ViewModelStoreOwner` → `NavDisplay` 渲染 `:shared` 的 `MainScreen` 与子页

### `DataLayerDesktop.kt`

数据层初始化：以 `AppDatabaseJvmFactory` 打开用户目录下的数据库，`Storage.initialize`，并把全部端口注册到各 Registry

### `CoreSelfCheck.kt`

Rust 核心自检（JNA 加载本机动态库），结果写入用户目录

应用图标以 `:shared` 的矢量源 `shared/src/commonMain/composeResources/drawable/app_icon.svg` 为唯一来源：运行期由 `platform/AppIcon.kt` 按目标尺寸栅格化（窗口、托盘、标题栏共用），底色为 `#0067B8` 圆角方块；打包期由 `generateIconIco` 任务调用 `tool/IconTool` 生成 `.ico`。产物运行方式见[窗口与打包](窗口与打包.md)。
