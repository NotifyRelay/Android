# `:desktop` — 叠加层

无边框、透明、置顶、点击穿透且不抢焦点的窗口，尺寸随内容收缩并固定在屏幕顶部居中，用 Compose 直接绘制媒体卡、超级岛卡片、罗技汇总岛、通知卡片与状态元素。叠加层契约见[桌面端](../../桌面端.md#overlay)，扩展点抽象见[模块结构](../../模块结构.md)。

## 布局

窗口内容只有一列，宽度固定为 `OVERLAY_COLUMN_WIDTH`（420dp），距屏幕顶部 10dp。列内自上而下为媒体卡、超级岛、通知卡片、状态行；整列尺寸经 `onSizeChanged` 交给 `DesktopWindowsOverlay.moveTo`，窗口随之改成「屏幕水平居中 + 内容尺寸」。

列由 `OverlayColumn` 按「独立行 + 填空隙」排布；条目以唯一键登记，内容不发出节点时（关闭的元素、空的文案）按零尺寸跳过，不占行也不占位：媒体卡、超级岛卡片、通知卡片与罗技汇总岛各占一条独立行并水平居中；时间、键盘、余额与收起态通知图标按顺序尝试填进这些独立行左右剩下的空档，左空档的条目整组贴向居中元素右侧、右空档整组贴向左侧，都不贴列边。填不下的条目留到后续独立行继续尝试，全部独立行处理完后仍未安置的按自身宽度折行、整体居中排在最下方。空档是否够用按实测宽度判定。

## 渲染

### `DesktopOverlayWindow.kt`

窗口与内容装配：创建透明无边框窗口，应用叠加层样式与点击穿透，启动置顶监控，并驱动帧时钟（频谱与映射提示淡出）与超级岛超时回收。可交互区域集合在此持有，经 `snapshotFlow` 提交给原生层；`DebugFlags.OVERLAY_REGION_DEBUG` 开启时叠加 `RegionDebugOverlay`。前台全屏检测开启且命中时整列内容不组合，窗口保持原尺寸。

### `NotificationCards.kt`

通知卡片层：卡片与图标方块两种形态。最多 2 张卡片同时展开，其余按到达顺序排队等前面的收起；每张展开 3 秒后收起为 24dp 图标方块，图标自收起时刻起存活 12 秒后移除。展开态为黑底圆角卡，左侧应用图标，右侧依次为「应用名 · 设备名」、标题与正文（正文最多两行）。展开态卡片独占一行并居中，收起态图标方块并入状态行参与流式排布。展开与收起状态由 `NotificationCardsState` 统一持有，巡检循环只跑一次，两处渲染读到同一份状态。图标方块是唯一可点击的通知元素，点击重新展开并登记可交互区域。

### `DesktopSuperIslandCard.kt`

超级岛卡片：按 `paramV2` 选择渲染方式（媒体大岛 / 摘要区 A-B / 模板组件），3 秒后收起为摘要胶囊，12 秒无更新被移除。仅摘要类业务（手电筒）不展开。

### `LogiIslandCard.kt`

罗技电池汇总岛：所有设备合并为一条与超级岛同形的卡片。两态都以设备名与电量图标为外显内容，收起态不显示具体电量值，设备名超出宽度时滚动显示；展开态逐台补上电量值与充电状态（离线、充电中、慢充、已充满、充电异常）。电量、充电状态或在线状态变化时自动展开 3 秒；交互开启时点击胶囊手动展开、点击展开态收起，胶囊登记为可交互区域。无可用设备时不绘制。设备集合由罗技开关与隐藏离线开关决定。

### `OverlayElements.kt`

状态元素渲染：时间、键盘、余额；文本为黑色描边层与彩色填充层叠放，无背景卡片。键盘元素为按键盒（蓝底白边圆角，每行最多 10 个，映射提示黑底显示在按键行下方并在最后 30% 时长淡出）：按下键全部映射为键名显示，Caps Lock 开启显示「大写」，Num Lock 常态开启、仅关闭时显示「NumLk关」，Scroll Lock 开启时显示。时间元素只读 `DesktopOverlayStore.clockText`，不自行计时。

### `OverlaySpectrum.kt`

频谱条动画：五条双波峰震荡的合成波形，随帧时钟推进。

### `DesktopWindowsOverlay.kt`

Win32 原生能力：窗口样式、置顶强化（peer 变化检测、最小化恢复、调用后验证）、点击穿透切换、前台全屏检测、`moveTo` 几何提交。以窗口坐标判定鼠标是否位于可交互区域内，仅在状态变化时把 `SetWindowLong` 投递到 EDT；原生操作失败后降级并停止重试。

### `DesktopSuperIslandInbound.kt`

超级岛入站处理：报文由 Rust core 归一后写入 `DesktopOverlayStore.superIslands`。

## 扩展点

### `DesktopOverlayFeatures.kt`

扩展点装配：持有四项 `OverlayFeature` 实现并统一启停；具体生命周期与数据订阅由各 Feature 自管，本类只做编排与供设置页访问的委托。`current` 供设置页即时同步

### `DesktopBalanceFeature.kt`

余额扩展点：实现 `OverlayFeature`，封装 `DesktopBalanceSource` 的生命周期与数据订阅，注册到 `OverlayFeatureRegistry`

### `DesktopLogiBatteryFeature.kt`

罗技电池扩展点：实现 `OverlayFeature`，封装 `DesktopLogiBatterySource`

### `DesktopKeyboardFeature.kt`

键盘扩展点：实现 `OverlayFeature`，封装 `DesktopKeyboardSource`

### `DesktopClockFeature.kt`

时间扩展点：实现 `OverlayFeature`，封装 `DesktopClockSource`（纯 JVM）

### `DesktopClockSource.kt`

时间数据源（纯 JVM，无 JNA）：`java.time.LocalTime` 按配置格式化，秒级或分钟级刷新

### `DesktopBalanceSource.kt`

DeepSeek 余额数据源：JDK `HttpClient` 轮询 `/user/balance`，优先取 CNY 余额；余额未变只刷新末条时间，变化时追加并算变化量；历史超 500 条时合并最旧的同向连续项

### `DesktopBalanceHistoryStore.kt`

余额历史持久化（JSON 落 `Storage`）

### `DesktopLogiBatterySource.kt`

罗技电池数据源：后台协程按 30 秒轮询枚举（阻塞 HID IO），结果与上次一致时不广播

### `LogiBatteryNative.kt`

`logi_battery.dll` 的 JNA 声明与枚举门面：结构体与 Rust `LbDeviceInfo` 逐字段对应，**对齐固定为 1**（Rust 侧最大对齐字段为 `u16`，结构体 266 字节，按平台默认对齐会算成 272 导致数组步长错位）；内部完成分配→读取→释放

### `DesktopKeyboardSource.kt`

键盘监控数据源：自建专用线程安装全局低级键盘钩子并泵消息循环（`WH_KEYBOARD_LL` 回调只投递到安装线程）；回调内只更新状态并合并推送，切换键在按下时翻转锁定状态（初值在安装时经 `GetKeyState` 读取）；修饰键以 `GetAsyncKeyState` 全局真值为准并每 50ms 轮询自愈（钩子漏掉抬起边沿时下次轮询清除）；推送按快照等值跳过，映射命中时投递提示

### `KeyboardHookBridge.kt`

钩子原生封装：`SetWindowsHookExW` / `UnhookWindowsHookEx` / `GetMessageW` 消息泵 / `PostThreadMessageW` 退出 / `GetKeyState` 读取 / `GetAsyncKeyState` 全局按下状态

## 开关口径

扩展点与显示层复用同一窗口，不引入宿主编排器：`DesktopOverlayFeatures` 在窗口创建后装配。开关口径为「叠加层总开关 + 各元素开关」同时满足才生效，总开关关闭时不创建窗口也不启动扩展点；键盘项的全局低级键盘钩子随该口径安装与卸载，不做常驻。默认值：余额默认关（填入凭据后由用户开启），罗技电池、键盘、时间默认开。余额与罗技的枚举/轮询在后台，键盘钩子在专用消息泵线程，均不占用渲染线程。非外观设置（交互、频谱、操作按钮、收起时长）经 `revision` 观察，切换即时生效。
