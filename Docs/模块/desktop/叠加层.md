# `:desktop` — 叠加层

无边框、透明、置顶、点击穿透且不抢焦点的窗口，用 Compose 直接绘制媒体卡、超级岛卡片与弹幕。叠加层契约见[桌面端](../../桌面端.md#overlay)，扩展点抽象见[模块结构](../../模块结构.md)。

## 渲染

### `OverlayElements.kt`

扩展点浮窗渲染：余额、罗技电池、键盘状态、时间；定位按「屏幕百分比锚点 + 内容居中」，文本为黑色描边层与彩色填充层叠放。罗技浮窗为单列卡片（黑色半透明圆角底 + 白色细边框），卡片内为 Segoe MDL2 电量图标（复用 `BatteryIconConverter` 的字形与分段着色）与设备名，设备名超长以省略号截断。键盘浮窗为按键盒（蓝底白边圆角，每行最多 10 个，映射提示黑底显示在按键行下方并在最后 30% 时长淡出）：按下键全部映射为键名显示，Caps Lock 开启显示「大写」，Num Lock 常态开启、仅关闭时显示「NumLk关」，Scroll Lock 开启时显示。时间浮窗只读 `DesktopOverlayStore.clockText`，不自行计时

## 扩展点

### `DesktopOverlayFeatures.kt`

扩展点装配：持有四项 `OverlayFeature` 实现并统一启停；具体生命周期与数据订阅由各 Feature 自管，本类只做编排与供设置页访问的委托。`current` 供设置页即时同步

### `DesktopBalanceFeature.kt`

余额扩展点：实现 `OverlayFeature`，封装 `DesktopBalanceSource` 的生命周期与数据订阅，注册到 `OverlayFeatureRegistry`

### `DesktopLogiBatteryFeature.kt`

罗技电池扩展点：实现 `OverlayFeature`，封装 `DesktopLogiBatterySource`

### `DesktopKeyboardFeature.kt`

键盘扩展点：实现 `OverlayFeature`，封装 `DesktopKeyboardSource`

### `DesktopClockFeature.kt`

时间扩展点：实现 `OverlayFeature`，封装 `DesktopClockSource`（纯 JVM）

### `DesktopClockSource.kt`

时间数据源（纯 JVM，无 JNA）：`java.time.LocalTime` 按配置格式化，秒级或分钟级刷新

### `DesktopBalanceSource.kt`

DeepSeek 余额数据源：JDK `HttpClient` 轮询 `/user/balance`，优先取 CNY 余额；余额未变只刷新末条时间，变化时追加并算变化量；历史超 500 条时合并最旧的同向连续项

### `DesktopBalanceHistoryStore.kt`

余额历史持久化（JSON 落 `Storage`）

### `DesktopLogiBatterySource.kt`

罗技电池数据源：后台协程按 30 秒轮询枚举（阻塞 HID IO），结果与上次一致时不广播

### `LogiBatteryNative.kt`

`logi_battery.dll` 的 JNA 声明与枚举门面：结构体与 Rust `LbDeviceInfo` 逐字段对应，**对齐固定为 1**（Rust 侧最大对齐字段为 `u16`，结构体 266 字节，按平台默认对齐会算成 272 导致数组步长错位）；内部完成分配→读取→释放

### `DesktopKeyboardSource.kt`

键盘监控数据源：自建专用线程安装全局低级键盘钩子并泵消息循环（`WH_KEYBOARD_LL` 回调只投递到安装线程）；回调内只更新状态并合并推送，切换键在按下时翻转锁定状态（初值在安装时经 `GetKeyState` 读取）；修饰键以 `GetAsyncKeyState` 全局真值为准并每 50ms 轮询自愈（钩子漏掉抬起边沿时下次轮询清除）；推送按快照等值跳过，映射命中时投递提示

### `KeyboardHookBridge.kt`

钩子原生封装：`SetWindowsHookExW` / `UnhookWindowsHookEx` / `GetMessageW` 消息泵 / `PostThreadMessageW` 退出 / `GetKeyState` 读取 / `GetAsyncKeyState` 全局按下状态

通知与超级岛的显示层在本模块的 `overlay` 包内：无边框、透明、置顶、点击穿透且不抢焦点的窗口，用 Compose 直接绘制媒体卡、超级岛卡片与弹幕；媒体卡展开态复用 `:superislandui` 的媒体大岛，超时后收起为摘要胶囊（短标题贴右对齐、频谱开关开启时频谱条贴右端常显），换曲时重新展开且不带操作按钮（仅用户点开的展开显示）；超级岛卡片与安卓浮窗共用 `:superislandui` 的 `SuperIslandTemplateCompose`（按 paramV2 分派媒体大岛 / 摘要区 / 模板组件）与 `SuperIslandExpandableCard`（展开/收起形态变换：宽高与圆角同进度插值、底色两态渐变、顶部锚定、先快后慢缓动），3 秒后收起为摘要胶囊、12 秒无更新自动移除。非锚点设置（交互、频谱、操作按钮、收起时长）经 `revision` 观察，切换即时生效。窗口的 TOPMOST 层级由 `DesktopOverlayTopmostMonitor` 持续校准（丢失即恢复、每秒重断言、跟随显示器尺寸），帧心跳超时则清除置顶。超级岛卡片的 `paramV2Raw` 布局解析待接入。

叠加层扩展点（余额 / 罗技电池 / 键盘 / 时间）复用同一窗口渲染，不引入宿主编排器：`DesktopOverlayFeatures` 在窗口创建后装配。开关口径为「叠加层总开关 + 各元素开关」同时满足才生效，总开关关闭时不创建窗口也不启动扩展点；键盘项的全局低级键盘钩子随该口径安装与卸载，不做常驻。四类默认值：余额默认关（填入凭据后由用户开启），罗技电池、键盘、时间默认开，罗技仅在枚举到设备时显示。余额与罗技的枚举/轮询在后台，键盘钩子在专用消息泵线程，均不占用渲染线程。
