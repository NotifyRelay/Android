# `:desktop` — 端口实现

`:desktop` 为 `:shared` 提供的各端口实现，均位于 `notifyrelay.desktop.platform` 包。端口注入的完整性要求见[模块结构](../../模块结构.md#port-injection)；窗口、托盘与打包相关的文件见[窗口与打包](窗口与打包.md)。

### `DesktopUiPorts.kt`

提示/剪贴板/跳转/主题（索引持久化到 `Storage`）/系统栏/位图端口实现

### `Win32Clipboard.kt`

Win32 剪贴板纯文本写入（JNA 调 user32/kernel32，写 `CF_UNICODETEXT`），绕开 AWT 写路径把 `\n` 换成 `\r\n`；提供 `normalizeNewlines`（`CRLF` → `LF`）与 `isAvailable`，非 Windows 时回落 AWT

### `DesktopClipboardSyncPort.kt`

桌面端剪贴板同步端口：监听系统剪贴板变更，内容交 Rust core 判定与发送，入站报文解码后写回剪贴板；平台侧不持有同步状态

### `ClipboardChangeMonitor.kt`

系统剪贴板变更监听（事件驱动）：`AddClipboardFormatListener` 加窗口过程子类化，只截获 `WM_CLIPBOARDUPDATE`，其余消息交回原窗口过程

### `DesktopExtraUiPorts.kt`

偏好/图片解码（data URL 与 http(s) 经 Skia 解码，LRU 32，最长边 320）/显示器/应用启动/主界面/设置端口实现

### `DesktopExtraPorts.kt`

端口实现：超级岛配置委托 `SuperIslandConfigPolicy`；音频中继与媒体控制为中性实现

### `DesktopFilterPorts.kt`

与 Android 共用 `RemoteFilterRepository` / `LocalFilterRepository` / `PinnedAppsRepository` 的端口实现

### `DesktopPlatformPorts.kt`

设备形态（非平板、无系统版本）、已安装包（恒空集）与 Rust 过滤能力端口

### `DesktopIconCodecPort.kt`

图标编解码端口：PNG 字节 ↔ Skia 位图；本机图标来源恒 null

### `DesktopSuperIslandHistoryPort.kt`

超级岛历史端口：分页源与历史存储复用 `:data` 实现，应用名回落包名、图标为 null

### `DesktopAppPorts.kt`

本机应用、远端应用列表与应用图标端口实现

### `DesktopHistoryPort.kt`

通知历史端口（直接读 Room）

### `DesktopDeviceListPort.kt`

设备列表电量与充电状态（取 `PowerStatusMonitor.snapshot`）、横屏端口实现；图标字体取 `:shared` 的 MDL2 字体

### `DesktopNotificationActionPort.kt`

通知历史交互端口实现

### `BatteryLevel.kt`

电源状态读取：Windows 经 kernel32 `GetSystemPowerStatus` 取电量与充电状态；提供无符号 `percent()` 与带符号 `signedPercent()`（正=充电、负=放电）；非 Windows 或读取失败回落 100／未充电

### `PowerStatusMonitor.kt`

电源状态变化监听：经 powrprof `PowerSettingRegisterNotification` 注册电池剩余电量与交流电来源两项系统通知，变化时刷新可观察快照并回调（供心跳调度器实时更新电量）

### `DesktopPairingDependencies.kt`

配对依赖注入：核对走 `NativePairingCorePort`，握手等待器取设备管理器的同一实例，电量取 `BatteryLevel.signedPercent()`，平台标识 `pc`

### `DesktopOverlaySettings.kt`

叠加层设置：叠加层总开关经 `Storage` 持久化；扩展点四类设置（余额开关与凭据与轮询间隔、罗技开关与隐藏离线与设备名覆盖、键盘开关与映射规则、时间开关与格式）与各状态元素的缩放/颜色/描边经内部 `Style` 读写。状态元素由叠加层固定列排布，`Style` 不保存位置；其字段以 Compose mutableState 为背景态，拖动滑块时直接写入触发重组，松手时经 `persist()` 落盘。另暴露 `revision` 与 `notifyChanged()` 供非外观设置（开关、显示格式等）观察变更

### `DesktopOverlaySettingsContent.kt`

叠加层设置主页（总开关 + 五个子页入口）与「通知与媒体卡」子页（测试通知卡片、媒体卡收起、操作按钮、频谱）。数值项一律用滑块，公共辅助为 `OverlaySlider` 与 `snapToStep`。`OverlaySlider` 回调拆分为 `onValueChange`（拖动期实时，更新背景态）与 `onValueChangeFinished`（松手落盘）

### `DesktopOverlayFeaturesContent.kt`

四个扩展点子页：余额（凭据录入与立即查询、轮询间隔）、罗技电池（隐藏离线、设备列表与立即刷新、设备名修改）、键盘（开关与映射的启用/删除/按键录入）、时间（显示秒与 24 小时制），以及各状态元素的缩放/描边滑块

### `KeyboardMappingStore.kt`

快捷键映射的 JSON 编解码，落到 `Storage`；解码失败按空列表处理并记告警

### `LogiDeviceNameStore.kt`

罗技设备自定义名的 JSON 编解码，落到 `Storage`；键为设备标识，解码失败按空表处理并记告警
