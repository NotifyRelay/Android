### 3.4 `:superislandui` 模块

此模块主要由 Compose UI 组件和数据模型类构成，包含了完整的小米超级岛 UI 渲染逻辑。核心类：
- `SuperIslandManager` - 悬浮岛管理（启用检测、协议版本、权限）
- `SuperIslandProtocol` - 协议处理（State、Diff、Payload 构建）
- `TextSplitter` - 文本分割工具
- `AParser`/`BParser` - A/B 组件解析器
- `ParamV2Renderer` - ParamV2 渲染器
- 各种 `*Data.kt` - 数据模型（BaseInfo, ChatInfo, HighlightInfo 等）
- 各种 `*Compose.kt` - Compose UI 组件（14 个 BigIsland 组件）

### 3.5 `:checkupdata` 模块

- `CheckUpdateManager` - 更新检查管理器
- `GitHubApiClient`/`GitHubApiService` - GitHub API 客户端
- `UpdateCache` - 更新缓存
- `SystemDownloader` - 系统下载器
- `VersionComparator`/`VersionRule` - 版本比较
- `CheckUpdateConfig`/`ReleaseInfo`/`UpdateResult` - 数据模型

### 3.6 `:scrcpy` 模块（子模块，外部维护）

- ADB 发现、配对、连接相关类
- Scrcpy 核心（`Scrcpy.kt`, `ClientOptions.kt`, `ServerParams.kt`）
- 音视频录制（`NativeAacRecorder`, `NativeWavRecorder`, `NativeMp4Recorder` 等）
- UI 页面（DevicePage, SettingsPage, ScrcpyScreenHost 等）
- 触摸事件处理
