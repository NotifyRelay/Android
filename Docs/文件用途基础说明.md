## 一、项目概览

### 1.1 项目信息

| 项 | 值 |
|---|---|
| 项目名（rootProject） | `NotifyRelay` |
| 仓库根目录 | `Android/`（工作区 `E:\GitHubCode\01Main\NotifyRelay\Android`） |
| 应用 ID / `:app` namespace | `com.xzyht.notifyrelay` |
| compileSdk / targetSdk | 37 / 37 |
| `:app` minSdk | 31（Android 12） |
| `:base` / `:data` / `:superislandui` / `:checkupdata` minSdk | 29（取 `libs.versions.minSdk`） |
| `:core` minSdk | 29（源码目录 `nativecore/`） |
| `:scrcpy` minSdk | 26（子模块自带配置） |
| 模块数量 | 7 个 |

### 1.2 模块清单

| 模块 | namespace | 说明 | 是否 Git 子模块 |
|---|---|---|---|
| `:app` | `com.xzyht.notifyrelay` | 主应用（UI、业务 feature、同步） | 否 |
| `:base` | `notifyrelay.base` | 基础工具库（无内部模块依赖） | 否 |
| `:data` | `notifyrelay.data` | 数据层（Room / 配置 / 持久化，依赖 `:base`） | 否 |
| `:superislandui` | `github.xzynine.superislandui` | 超级岛（SuperIsland）悬浮 UI 渲染 | 否 |
| `:checkupdata` | `github.xzynine.checkupdata` | 更新检查 | 是 |
| `:scrcpy` | `io.github.miuzarte.scrcpyforandroid` | Scrcpy 投屏 | 是 |
| `:core` | `com.xzyht.notifyrelay.nativecore` | Rust 核心 FFI 绑定（JNA），依赖 `:base` | 否（内含 `notify-relay-core` 子模块） |

`:core` 的 Gradle 模块名与源码目录不同名，`settings.gradle.kts` 中以
`project(":core").projectDir = file("nativecore")` 重定向。

LSPosed 模块位于平级独立仓库 `NotifyRelay-LSP`（独立 APK，不参与本仓库构建）。

子模块配置（`.gitmodules`）：

- `checkupdata` → `git@github.com:xzy-nine-common/checkupdata-android.git`（branch `main`）
- `scrcpy` → `git@github.com:xzy-nine/ScrcpyForAndroid.git`（branch `library`）
- `nativecore/notify-relay-core` → `https://github.com/NotifyRelay/core.git`（branch `main`）

根 `build.gradle.kts` 对 `checkupdata`/`scrcpy` 不应用 ktlint。

### 1.3 模块依赖关系

```
:app ──┬── :data ─────────── :base
       ├── :base
       ├── :superislandui ─┬ :base
       │                   └── :data ── :base
       ├── :scrcpy ────────┬ :base
       │                   └── :data ── :base
       ├── :core ─────────── :base      （Rust FFI，源码目录 nativecore/）
       ├── :checkupdata        （无内部依赖）
       └── :base
```

`buildSrc/` 为 Gradle 构建辅助工程。Rust 侧代码位于 `nativecore/notify-relay-core`。

### 3.5 `:core`

`NativeCore`（object）是 Rust 核心 `notify-relay-core` 的 JNA 绑定门面，覆盖：

- 会话：`createContext()`, `exportState()`, `importState()`, `encryptLocalState()`, `decryptLocalState()`
- 加密：`generateKeypair()`, `getPublicKey()`, `hasKeypair()`, `deriveSharedSecret()`, `migrateSharedSecret()`, `deriveFtpCredentials()`, `derivePasswordHash()`, `generateRandomPassword()`
- 设备：`getLocalUuid()`, `renameDevice()`, `getDeviceList()`, `removeDevice()`, `removeDeviceSession()`
- 连接/配对：`periodicBroadcast()`, `sendHandshake()`, `connectDevice()`, `sendPairingInit()`, `sendPairingResp()`, `sendAccept()`, `sendReject()`, `generatePairingCode()`, `clearPairingCode()`
- 消息：`enqueueMessage()`, `computeDedupKey()`, `computeFeatureId()`, `dedup()`, `shouldDeduplicate()`
- 过滤：`setFilterConfig()`, `mapLocalPackage()`, `checkFilterMode()`
- 同步：`clipboardOnChanged()`, `clipboardOnReceived()`, `appSyncPrepareIconRequest()`, `appSyncClearIconPending()`, `appSyncParseIconResponse()`, `appSyncBuildApplistRequest()`, `appSyncParseApplistResponse()`
- 状态推送：`pushSuperislandState()`, `pushMediaState()`, `setOnStateQueryCallback()`, `onNetworkChanged()`, `getLocalIp()`

`NotifyRelayCore` 提供 JNA 库加载与 `ptrToStringAndFree()` 辅助。

### 3.6 `:lsp`（独立仓库）

LSPosed 模块位于独立仓库 `NotifyRelay-LSP`（独立 APK，headless、无 GUI），
不参与本仓库构建，源码见该仓库 `app/src/main/java/com/xzyht/notifyrelay/lsp/`：

- `XposedInit` — LSPosed 模块入口（继承 `XposedModule`），负责作用域判定与 Hook 安装。
- `XmsfAuthFix` — 超级岛鉴权绕过实现。

## 四、构建相关

- 版本号来自根目录 `version.properties`（由 `update.yml` 在 push 到 `main` 时按 conventional commits 语义回写）；CI 可用 `-PversionName/-PversionCode` 或环境变量 `VERSION_NAME/VERSION_CODE` 覆盖。
- `:app` 在 release 构建时启用 ABI splits（`arm64-v8a`、`x86_64` + universal），debug 仅生成 universal APK。
- `preBuild` 依赖 `generatePermissionNotes`：解析 `AndroidManifest.xml` 中 `<uses-permission>` 上方注释，生成 `res/raw/permission_notes.txt`，供协议页（`GuideAgreementPage`）展示权限用途。**权限用途只需维护 Manifest 注释，不要在 Kotlin 中手抄**。
- `:app` 声明 `aidl = true`、`buildConfig = true`、Compose 开启。LSPosed 入口声明（`META-INF/xposed/*`）不合并进主 APK。
- ktlint 应用于除 `checkupdata`、`scrcpy` 之外的所有模块。
