### 1.2 模块清单

| 模块 | namespace | 说明 | 是否 Git 子模块 |
|---|---|---|---|
| `:app` | `com.xzyht.notifyrelay` | 主应用；Android 应用模块，承载 Manifest 组件与各端口实现 | 否 |
| `:desktop` | — | 桌面端入口；KMP 库（jvm 单目标），复用 `:shared` 界面与各端口 | 否 |
| `:overlay-api` | `notifyrelay.overlay.api` | 叠加层扩展点契约；KMP 库（jvm 单目标），只放数据模型与能力接口，无实现 | 否 |
| `:base` | `notifyrelay.base` | 基础设施层；KMP 库（android + jvm 双目标），日志/时间/摘要/文本/颜色工具在 commonMain，平台工具在 androidMain | 否 |
| `:domain` | `notifyrelay.domain` | 领域层；KMP 库（android + jvm 双目标），领域模型与端口契约全在 commonMain | 否 |
| `:data` | `notifyrelay.data` | 数据层；KMP 库（android + jvm 双目标），Room 声明、迁移与存储/仓储逻辑在 commonMain，平台差异在 androidMain/jvmMain | 否 |
| `:shared` | `notifyrelay.shared` | 公共界面层；KMP 库（android + jvm 双目标），页面/组件/ViewModel 全在 commonMain | 否 |
| `:superislandui` | `github.xzynine.superislandui` | 超级岛（SuperIsland）悬浮 UI 渲染；KMP 库（android 单目标），平台无关代码在 commonMain | 否 |
| `:checkupdata` | `github.xzynine.checkupdata` | 更新检查；KMP 库（android + jvm 双目标），全部逻辑在 commonMain，平台差异在 androidMain/jvmMain | 是 |
| `:scrcpy` | `io.github.miuzarte.scrcpyforandroid` | Scrcpy 投屏；Android 库 | 是 |
| `:core` | `com.xzyht.notifyrelay.nativecore` | Rust 核心 UniFFI 绑定；KMP 库（android + jvm 双目标），`NativeCore` 门面与绑定 expect 声明在 commonMain | 否（内含 `notify-relay-core` 子模块） |

`:core` 的 Gradle 模块名与源码目录不同名，`settings.gradle.kts` 中以 `project(":core").projectDir = file("nativecore")` 重定向。

LSPosed 模块位于平级独立仓库 `NotifyRelay-LSP`（独立 APK，不参与本仓库构建）。

子模块配置（`.gitmodules`）：

- `checkupdata` → `git@github.com:xzy-nine-common/checkupdata-android.git`（branch `main`）
- `scrcpy` → `git@github.com:xzy-nine/ScrcpyForAndroid.git`（branch `library`）
- `nativecore/notify-relay-core` → `https://github.com/NotifyRelay/core.git`（branch `main`）
- `desktop/smtc-rust` → `https://github.com/xzy-nine-common/SMTC_Rust.git`（branch `master`）
- `desktop/logi-battery` → `https://github.com/xzy-nine/logi-battery.git`（罗技 HID++ 电量枚举，C ABI 动态库）

根 `build.gradle.kts` 对 `checkupdata`/`scrcpy` 不应用 ktlint。

### 1.3 模块依赖关系

```
:app ──┬── :shared ────┬── :base（基础设施层）
       │               ├── :domain（领域模型与端口契约）
       │               ├── :data（数据层仓储；超级岛设置与历史分页共用）
       │               └── :checkupdata（更新检查）
       ├── :domain ──────────── :base
       ├── :data ────────────┬── :base
       │                     └── :domain
       ├── :core ────────────┬── :base（Rust 核心，源码目录 nativecore/）
       │                     └── :domain
       ├── :superislandui ───┬── :base
       │                     └── :data
       ├── :checkupdata        （无内部依赖）
       └── :scrcpy ──────────┬── :base
                             └── :data
:desktop ──┬── :shared
           ├── :domain
           ├── :data
           ├── :core
           ├── :overlay-api
           └── :base
```

`:base` 为最底层（无内部依赖）；`:domain` 只依赖 `:base`；`:data` 依赖 `:base` 与 `:domain`；`:shared` 依赖 `:base`、`:domain`、`:data` 与 `:checkupdata`。

`:overlay-api` 无内部依赖，只被 `:desktop` 消费。

`:data` 不依赖 `:shared` 与 `:core`；需要 Rust 过滤能力与已安装包集合时经 `:domain` 的 `NativeFilterPort` / `InstalledPackagesPort` 注入。

`buildSrc/` 为 Gradle 构建辅助工程。Rust 侧代码位于 `nativecore/notify-relay-core`。

| 模块 | 包根 |
|---|---|
| `:app` | `app/src/main/java/com/xzyht/notifyrelay/` |
| `:desktop` | `desktop/src/jvmMain/kotlin/notifyrelay/desktop/` |
| `:overlay-api` | `overlay-api/src/jvmMain/kotlin/notifyrelay/overlay/api/` |
| `:base` | commonMain：`base/src/commonMain/kotlin/notifyrelay/base/`；androidMain：`base/src/androidMain/kotlin/notifyrelay/base/`；jvmMain：`base/src/jvmMain/kotlin/notifyrelay/base/` |
| `:domain` | commonMain：`domain/src/commonMain/kotlin/notifyrelay/domain/` |
| `:data` | commonMain：`data/src/commonMain/kotlin/notifyrelay/data/`；androidMain：`data/src/androidMain/kotlin/notifyrelay/data/`；jvmMain：`data/src/jvmMain/kotlin/notifyrelay/data/` |
| `:superislandui` | commonMain：`superislandui/src/commonMain/kotlin/github/xzynine/superislandui/`；androidMain：`superislandui/src/androidMain/kotlin/github/xzynine/superislandui/` |
| `:checkupdata` | commonMain：`checkupdata/src/commonMain/kotlin/github/xzynine/checkupdata/`；androidMain：`checkupdata/src/androidMain/kotlin/github/xzynine/checkupdata/`；jvmMain：`checkupdata/src/jvmMain/kotlin/github/xzynine/checkupdata/` |
| `:scrcpy` | `scrcpy/src/main/java/io/github/miuzarte/scrcpyforandroid/` |
| `:core` | commonMain：`nativecore/src/commonMain/kotlin/com/xzyht/notifyrelay/nativecore/`；androidMain：`nativecore/src/androidMain/kotlin/com/xzyht/notifyrelay/nativecore/`（绑定生成物位于 `nativecore/build/generated/uniffi-kmp/`） |
