# 构建与验证

本文是构建环境、编译警告基线与代码检索的当前口径。模块结构与依赖见[模块结构](模块结构.md)与[文件用途基础说明](文件用途基础说明.md)。

<a id="environment"></a>

## 构建环境

Gradle 包装器要读写 `C:\Users\WINDOWS\.gradle`，构建需要 `danger-full-access` 文件权限；`workspace-write` 沙箱下会被拒。

pwsh 调用 gradlew 时属性必须加引号：`"-Pkotlin.incremental=false"`。不加引号会被参数解析拆散并报 `Task '.key=value' not found`。

原生产物 `nativecore/notify-relay-core/build` 约 17GB。多工作树用目录联接复用，构建全局串行。

crates.io 直连不可达，用 rsproxy 镜像：

```sh
cargo <cmd> --config 'source.crates-io.replace-with="rsproxy-sparse"' \
  --config 'source.rsproxy-sparse.registry="sparse+https://rsproxy.cn/index/"'
```

`gobley-uniffi-bindgen` 单独安装：`cargo install gobley-uniffi-bindgen --version 0.3.7 --locked`。

## 编译警告基线

当前基线：`:app` 13 条、全模块 29 条。

其中 `:app` 的 4 条来自 `ui/devtools/NotificationFieldDump.kt` 读取 `audioAttributes`、`contentView`、`bigContentView`、`headsUpContentView`。这四个字段无等价非废弃 getter，而全字段转储必须原样呈现，属必要警告。

<a id="clean-warning-build"></a>

## 取干净的全量警告

```sh
gradlew :app:compileDebugKotlin --no-build-cache "-Pkotlin.incremental=false"
```

Gradle 9.7.1 起 `--rerun` 全局选项已不存在，只剩会连带重跑原生任务的 `--rerun-tasks`。Gradle 用内容哈希指纹，`touch` 时间戳无效，必须让源码内容真实变化（例如在目标文件尾部追加一个无害空行驱动 out-of-date）。否则任务 `UP-TO-DATE` 或 `FROM-CACHE`，不打印警告。前后两侧命令必须一致。

## 警告比对

按「`<相对路径>|<消息>` 计数」判定新增与消失，去掉行号。警告文本自带的 `:行:列` 会让任何行号平移被误判成「新增加消失」。

## 代码检索

工作区根 `E:\GitHubCode\01Main\NotifyRelay\.codegraph\` 有 CodeGraph 索引，`Android/` 自身无索引。`codegraph_explore` 的 `projectPath` 必须传工作区根。

<a id="worktree"></a>

## 工作树与子模块

路径归一化同时覆盖主克隆根与工作树根，大小写敏感，不猜工作树命名；按 `git rev-parse --show-toplevel` 剥离。

`git worktree` 不检出子模块，需从主克隆 `.git/modules/<name>` 本地克隆并 checkout 到 `git ls-tree` 记录的提交。

删除工作树前先断目录联接，否则递归删除会穿透联接销毁主克隆产物。Windows 长路径用 `robocopy /MIR` 空目录兜底。
